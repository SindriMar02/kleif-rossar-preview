How many people can stay in the Barn?+

Please ask Erla for the current guest capacity and bedroom configuration. We have not published an unverified number in this example.

Can we combine it with the Farm?+

Yes. The two villas can be rented together, subject to availability. Tell the host about your group so the accommodation can be planned properly.

Is the game barn an event venue?+

The owner describes a game barn for family and friends. Event use, capacities and arrangements need to be discussed separately; they are not guaranteed by a villa booking.
